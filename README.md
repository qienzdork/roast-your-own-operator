# Roast Your Own Operator in One Line

A single original roast line, written by a small deterministic Python program
to `OUTPUT_PATH` (default `/output/entry.txt`). The line needles the operator
the way a friend teases: 3am prompts, vague instructions ("just make it
work"), and the agent who never sleeps watching the human who refuses to.
